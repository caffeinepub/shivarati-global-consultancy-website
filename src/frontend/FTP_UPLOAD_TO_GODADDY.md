# FTP Upload to GoDaddy Guide

This guide provides step-by-step instructions for uploading your static website to GoDaddy hosting via FTP.

## Important: Static Website Package

**This is a static HTML/CSS/JavaScript website, not a Java application.** You are uploading standard web files that work with GoDaddy's web hosting service. No Java runtime, server configuration, or special setup is required.

## Prerequisites

1. **GoDaddy Hosting Account**: Active web hosting plan with GoDaddy
2. **FTP Credentials**: Available in your GoDaddy hosting control panel
3. **Export ZIP**: Generated using the instructions in [GO_DADDY_EXPORT.md](./GO_DADDY_EXPORT.md)
4. **FTP Client**: FileZilla (recommended), Cyberduck, or any FTP client
