# GoDaddy Export Guide

This guide explains how to generate a static HTML/CSS/JS export package for uploading to GoDaddy hosting via FTP.

## Important Note

**This export produces static website files (HTML/CSS/JavaScript), not Java code.** The deliverable is a standard static website package that works with any web hosting service, including GoDaddy's FTP hosting. No Java runtime or server configuration is required.
